# 🎁 Sistema de Fidelidade - Barbearia Jorge Rodrigues

## 💎 O QUE É

Um programa de **fidelização digital** que recompensa seus clientes mais fiéis com **serviços gratuitos**.

---

## 🎯 COMO FUNCIONA

### Para o Cliente:
1. **Cadastra-se gratuitamente** pelo site (demora 30 segundos)
2. **Recebe um cartão digital** no WhatsApp
3. **A cada visita**, ganha pontos automaticamente
4. **Acumula pontos** e troca por serviços grátis

### Regra SUPER Simples:
```
✂️ 1 VISITA = 1 PONTO
```

**Não importa o serviço! Cada vez que visita, ganha 1 ponto!**

**Exemplos:**
- Veio cortar? = **1 ponto**
- Veio fazer barba? = **1 ponto**  
- Veio fazer corte + barba? = **1 ponto**
- Qualquer serviço = **1 ponto**

**SIMPLES ASSIM!** 🎯

## 📱 COMO FUNCIONA NA PRÁTICA

### Fluxo do Cliente:

1. **Cadastro:**
   - Entra no site
   - Clica em "Ativar Cartão Fidelidade"
   - Coloca nome e WhatsApp
   - Recebe cartão digital no WhatsApp

2. **Uso:**
   - Cada vez que corta, você credita os pontos manualmente
   - Cliente acompanha pelo WhatsApp
   - Quando atingir pontos suficientes, avisa que quer resgatar

3. **Resgate:**
   - Cliente chega e diz: "Quero usar meu corte grátis"
   - Você verifica os pontos
   - Zera os pontos usados
   - Cliente sai feliz e já começa a acumular de novo

### Fluxo para Você (Barbeiro):

**Opção Simples (sem backend automático):**
- Mantém uma planilha Excel ou Google Sheets
- Colunas: Nome | WhatsApp | Pontos Atuais | Última Visita
- Atualiza manualmente após cada atendimento

**No futuro (upgrade):**
- Sistema automatizado conectado com WhatsApp Business API
- Notificações automáticas quando cliente atinge pontos
- Dashboard para gerenciar tudo
