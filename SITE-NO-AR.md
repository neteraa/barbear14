## 📱 COMO USAR O SISTEMA DE CHECK-IN

### Para o Barbeiro (Jorge):

1. **Cliente chega na barbearia**
2. **Clique no botão "Check-in Rápido"** (hero do site)
3. **Digite o nome do cliente**
4. **Sistema mostra:**
   - QR Code único
   - Última visita
   - Total de visitas
   - Pontos acumulados
5. **Clique em "Registrar Visita Agora"**
6. **Pronto!** Cliente ganha +3 pontos automaticamente

### Para o Cliente:

**No futuro (upgrade):**
- Cliente pode escanear o QR Code com câmera do celular
- Fazer check-in automático
- Ver próprios pontos
- Resgatar prêmios online

**Por enquanto (MVP):**
- Barbeiro registra manualmente
- Sistema funciona localmente
- Sem backend (economia de custos!)

## 💾 ONDE ESTÃO OS DADOS?

**LocalStorage do Navegador:**
- Cada cliente tem ID único
- Dados salvos: nome, visitas, pontos, histórico
- Persiste mesmo fechando o navegador
- **Backup recomendado:** Exportar dados periodicamente

**Como acessar (para debug):**
1. Abra o site
2. Aperte F12 (DevTools)
3. Vá em "Application" > "Local Storage"
4. Procure por `barbear14_clientes`
